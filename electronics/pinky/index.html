What is Pinky?

Pinky is a microcontroller board similar to an Arduino that I designed from scratch. It uses a PIC16f15243 microcontroller, and is desiigned for controlling multiple child boards.

    Features:

  • USB programmable via bootloader
  • Programmable via custom Arduino+Python program
  • 3 4-pin SPI port
  • TisLib UI integration
  • 10 GPIO pins
  • 2x 5V and GND pins
