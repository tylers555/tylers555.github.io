What is Snail Jumpy?

Snail Jumpy is a video game that a friend and I worked on for several years, and what I used to learn programming in C/C++.

You play as a purple mushroom like character who needs to get to a certain end point in the level. However, to reach this seemingly simple object, you need to consider how each enemy affects you and the environment surroundings.

Every feature of this game was programmed by me, from scratch, using only three of the STB libraries.

The original Snail Jumpy

The first version written only using the SDL library and is best considered as a demo. However, as this was the first real progrmaming project I had done, the codebase was kind of a mess. This is what inspire me to go about making a second version of the game.

This game used only the SDL library, with everything else being written by me.
