What is TisLib?

TisLib is a cross platform library designed to simplify graphical application development, and is home to a large number of features.

    Module list:

  • Fundamentals
  • Crossplatform OS abstraction
  • Advanced GUI
  • Simplified renderer
  • Resource/settings management

OS

    Features:

  • Virtual memory management
  • Heap memory managment
  • Window management
  • File IO
  • Socket IO
  • Serial port IO

UI

    Features:

  • Plethora of widgets
  • Dynamic layouts
  • Panel based control
  • Keyboard naviragtion
  • DPI aware
  • IO stream integration

Basics

    Features:

  • Memory arena
  • Linked lists
  • Static and dynamic arrays
  • Bucket array
  • Versatile math functions
  • Linear algebra (vectors and matrices)

Render

    Features:

  • Texture management
  • Framebuffer management
  • Vertex and index buffer management
  • Shader program management
  • Optional push buffer API for simplicity
  • Numerous rendering primitives

Resources

    Features:

  • DPI awareness
  • Key and mouse bindings
  • Hotloaded variables
  • Resource updating
  • Multiple file format loading
    (PNG, WAV, TTF)
  • IO streams
